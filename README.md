# 小鲁班桌面宠物

一款面向 Windows 11 的离线 WPF 桌面宠物。小鲁班会趴在枕头上打呼噜、响应点击、在屏幕边缘探头，支持待办事项、循环定时提醒、免打扰、开机自启、多屏和高 DPI。

当前工作树源码版本：`v1.0.53`，基于用户指定的 `v1.0.48` 发布程序恢复并开发。程序不需要联网、账号或后台服务，当前版本也不会创建文件日志。GitHub Release 可能晚于源码；下载用户应以具体 Release 页的版本号和说明为准。

## 快速开始

1. 从 [GitHub Releases](https://github.com/guoqihan342-svg/xlb-pet/releases) 下载目标版本的 `LubanDesktopPet.exe`，并先阅读该版本说明。仓库中的 `dist/` 是本地发布目录，不随 Git 克隆分发。
2. 安装 Windows x64 `.NET 8 Desktop Runtime`。项目已使用 `8.0.29` 验证；[版本、官方下载地址和 SHA-512](runtime/dotnet-desktop-runtime-8.0.29-win-x64/README.md) 单独记录在仓库中。
3. 双击 `LubanDesktopPet.exe`。程序是框架依赖单文件，EXE 不包含 .NET 运行时。
4. 退出时请在 Windows 通知区域右键小鲁班图标，选择“退出小鲁班”。

> 当前 EXE 没有商业代码签名。从网络下载后，Windows SmartScreen 可能显示未知发布者提示。请先确认 Release 来源；如发布说明提供 SHA-256，再核对哈希后运行。

## 主要功能

- 7 种点击动作；空闲时约每分钟从这些动作和打呼噜待机中随机选择一次。跑步动作已完整移除。
- 趴枕头打呼噜待机，鼻尖只显示一个半透明呼吸泡泡。
- 待机时可点击头顶“去打工”胶囊按钮，让小鲁班坐在电脑前自然敲键盘。96 帧循环按 8 次不等间隔安排四指落键，并由 v5 语义手/袖口蒙版驱动真实指节与手腕跟随；单击只敲一次帽子后回到普通速度，双击才会连续切入至少 4 秒的认真打字。
- 拖到屏幕左、右、下边缘后播放探头动画；人物可拖到当前屏幕工作区最上沿，但顶部不吸附、不探头。
- 默认每次空闲约 10 分钟触发带铃铛和竹筒的大头熊猫坐骑巡游，支持双屏、负坐标副屏和不同 DPI。
- 待办事项支持新增、完成、修改、删除、正文复制和拖拽排序。
- 定时任务精确到秒，支持单次或每 N 分钟/小时/天循环、每日免打扰、漏提醒计数和分页提醒。
- 桌宠大小可在 75%～140% 之间连续调节；绕屏开关、大小和任务数据会持久化。
- 当前用户级开机自启，不需要管理员权限。

## 操作速查

| 操作 | 结果 |
| --- | --- |
| 左键单击小鲁班 | 依次播放 7 种可爱动作 |
| 待机或左/右/下边缘吸附时点击“去打工” | 普通待机直接开工；吸附时先自然缩回、退出边缘状态，再坐到电脑前 |
| 打工时左键单击小鲁班 | 小手轻敲一下帽子，然后回到普通 1 倍速打字 |
| 打工时左键双击小鲁班 | 立即把当前动作连续加速到 2 倍；在最近的精确中性接缝用约 133 ms 换成认真眉形，再完整保持至少 4 秒认真打字；已在认真状态时会续期 |
| 打工时点击“下班啦” | 平滑收工并回到原待机状态 |
| 按住左键拖动 | 移动桌宠；松手时判断左、右、下边缘吸附 |
| 右键单击小鲁班 | 打开或收起“待办事项 / 定时任务”面板 |
| 巡游中左键单击 | 在当前位置平滑下坐骑并回到待机，不追加点击动作 |
| 巡游中开始拖动 | 立即结束巡游的位置控制并由鼠标接管 |
| 巡游中右键单击 | 在当前位置平滑下坐骑，然后打开默认待办页 |
| 待办输入框按 `Enter` | 新增待办 |
| 选中待办正文后按 `F2` | 打开独立修改窗口 |
| 拖动待办左侧 `≡` | 调整待办顺序 |
| `Ctrl+C / Ctrl+X / Ctrl+V` | 在可编辑或可选择文字中复制、剪切、粘贴 |
| 提醒窗口点击“知道啦”、`×` 或按 `Esc` | 确认当前实际载入的提醒批次 |
| 任务面板点击“退出”，或通知区域右键小鲁班图标 | 正常保存并退出程序 |

更完整的交互、定时规则、免打扰和常见问题见 [用户指南](docs/USER_GUIDE.md)。

## 本地数据与隐私

所有业务数据默认保存在当前 Windows 用户目录：

| 位置 | 内容 |
| --- | --- |
| `%LocalAppData%\LubanDesktopPet\todos.json` | 待办文字、完成状态和顺序 |
| `%LocalAppData%\LubanDesktopPet\scheduled-tasks.json` | 定时任务、循环规则、下一次时间和免打扰设置 |
| `%LocalAppData%\LubanDesktopPet\settings.json` | 绕屏开关和桌宠大小 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `LubanDesktopPet` | 当前用户开机自启命令；不写入 `settings.json` |

- 程序不上传这些数据，也不需要网络访问。
- 当前版本不创建 `log/` 文件夹或其他文件日志。
- 程序使用当前会话单实例锁；重复双击不会启动第二个进程。
- 备份前应先从托盘正常退出，再复制整个 `%LocalAppData%\LubanDesktopPet` 文件夹。恢复时也应保持程序关闭。
- 卸载时先取消“开机自启”并正常退出，再删除 EXE；本地 JSON 是否保留由用户自行决定。

## 从源码运行

日常代码修改只需要 .NET 8 SDK，不需要重新生成动画素材：

```powershell
dotnet restore .\DesktopPet.csproj
dotnet run --project .\DesktopPet.csproj
dotnet build .\DesktopPet.csproj -c Release

# 存储契约
dotnet run --project .\tests\TodoStoreChecks\TodoStoreChecks.csproj -c Release

# 完整 WPF 状态契约
dotnet run --project .\tests\UiStateChecks\UiStateChecks.csproj -c Release
```

框架依赖单文件发布：

```powershell
dotnet publish .\DesktopPet.csproj -c Release -r win-x64 `
  --self-contained false -p:PublishSingleFile=true -p:DebugType=None `
  -o .\dist
```

当前发布物超过 GitHub 普通 Git 对象的 `100 MiB`（`104,857,600` 字节）硬限制，参见 [GitHub 大文件说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。`dist/**/*.exe` 和运行时安装包都已忽略，必须作为 GitHub Release 附件分发，不能提交到 Git 历史。

## v1.0.53 摘要

- 打工序列更新为 `48 / 96 / 48 / 96 / 24` 帧；普通 96 帧循环为 `1.6 秒`，认真循环保持同一动作相位并以 2 倍速播放。
- 一圈包含 9 个像素级精确的中性接缝、65 张独特位图和 8 次不等间隔四指落键；最长中性停顿只有 5 帧，四根目标手指实测位移为 `5.528–6.049 px`。
- 手与袖口改由 v5 语义蒙版和独立关节控制点驱动，非动作区域逐像素零漂移，不再把整只手或键盘一起拉扯。
- 单击只播放 48 帧敲头并回到普通 1 倍速；双击立即以 2 倍速延续当前姿势，到最近精确接缝后播放约 `133 ms` 的认真眉过渡，再完整保持 4 秒 2 倍速认真打字。待办事项和定时任务功能未改动。

## v1.0.52 摘要

- 普通与认真打字循环均重建为 48 帧全唯一序列：普通循环以 1 倍速每 `0.8 秒`一圈，认真循环以 2 倍速每 `0.4 秒`一圈。
- 四根手指分别使用独立触键轨迹，每次只让目标手指落键；袖口、掌根、非目标手指和键盘逐帧保持静止，避免整只手掌漂移或键盘跟随变形。
- `work-enter`、`work-loop`、`work-tap`、`work-serious-loop`、`work-serious-exit` 的帧数依次为 `48 / 48 / 48 / 48 / 24`；当前 Brotli v4 图集为 53 页、1600 个逻辑帧。
- “去打工 / 下班啦”、左/右/下边缘入口、认真状态至少 4 秒及待办事项和定时任务契约保持不变。

## v1.0.51 摘要

- 普通与认真打字改为真实左右手关键姿势驱动：每个 24 帧周期依次经过中性、左手抬起落键、中性、右手抬起落键和中性，72 帧运行契约由该周期确定性重复三轮。
- 双击或单击敲头后的认真打字继续使用 2 倍速，完整手势周期为 `0.2 秒`；认真眉形使用单条连续几何过渡，不再出现双眉重影。
- 手臂只在局部预乘 Alpha 区域替换，旧手位置会完整擦除；头脸、电脑和画布逐像素锁定，普通/认真循环最低 Alpha IoU 为 `0.996528`。
- “去打工 / 下班啦”、左/右/下边缘入口、侧边支撑手臂修复及待办事项和定时任务契约保持不变。当前图集仍为 55 页、1648 个源帧和 1648 个分页帧。

## v1.0.50 摘要

- 普通打工循环改为更自然的双手交替敲键盘；人脸、电脑和帧之间的整体比例仍保持稳定。
- 单击先完整播放敲头反应，再无缝进入至少 4 秒的 2 倍速认真打字；双击直接进入认真打字，重复双击会续期。
- 左、右、下边缘吸附仍显示“去打工”；点击后先播完可见的缩回衔接，再严格从待机入口开工。顶部仍不吸附。
- 新增 72 帧 `work-serious-loop` 和 24 帧 `work-serious-exit`；当前 Brotli 分页图集为 55 页、1648 个源帧和 1648 个分页帧。待办事项和定时任务模块没有修改。

## v1.0.49 摘要

- 以用户指定的 `v1.0.48` EXE 为恢复基线，只增加独立打工状态；待办事项、定时任务、提醒和持久化模型保持不变。
- 新增头顶萌系胶囊按钮、坐在电脑前的 60 fps 打字循环、单击轻敲帽子和双击 4 秒加速；单击会等待系统双击窗口，确认不是双击后才执行。
- 打工动画继续使用同一 `CompositionTarget.Rendering + Stopwatch` 绝对时间轴，脸、双眼和电脑主体逐帧固定，不使用整图交叉淡化。
- 提醒、拖动、右键和会话切换可安全抢占打工状态；退出工作后回到稳定待机，不自动触发普通点击动作。

## v1.0.48 基线摘要

- 保持 `399×509` 渲染、全部动画帧和 `64/104 MiB` 活动峰值预算不变；稳定空闲缓存目标由 `32 MiB` 收到 `24 MiB`，实测托管空闲热集减少约 `9 MiB`。
- 静止的左、右、下边缘探头现在也能在宽限期后释放旧动作页；运动期间仍禁止回收，边缘序列页不会被误删。
- 修复相邻像素桶状态，并保持工作站 GC、硬件渲染和异步预取；只在完全空闲、淘汰债务达到门槛且受 30 秒限频保护时请求 .NET 8 反提交空闲 GC 段，不使用周期性 GC 或强制清空工作集制造表面低占用。
- 最终 EXE 实测：自动动作期间私有工作集峰值约 `421.5 MiB`，动作结束后回落到 `193–200 MiB`，接近启动空闲的 `189–191 MiB`；回收发生在空闲阶段，不减少帧数或渲染分辨率。
- 顶部拖动同时补齐动画换帧贴顶、跨 DPI 抓点和捕获失败回滚；本机真实鼠标验证仍为 `contact=0px`、`work=0px`。

最终本地发布仍只以根目录 `dist/LubanDesktopPet.exe` 为主文件。`dist/` 不进入 Git，正式对外分发仍应使用 GitHub Release 附件。
