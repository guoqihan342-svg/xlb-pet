# 小鲁班桌面宠物用户指南

本指南面向直接使用 `LubanDesktopPet.exe` 的用户。开发、架构、素材和发布说明分别见 [开发说明](DEVELOPMENT.md)、[架构与状态机](ARCHITECTURE.md)、[动画与图集管线](ANIMATION_PIPELINE.md) 和 [测试与发布](TESTING_AND_RELEASE.md)。

## 1. 安装与启动

### 系统要求

- Windows 11 x64。
- x64 `.NET 8 Desktop Runtime`。`8.0.29` 是当前已验证版本，不要求用户只能安装这一补丁版本。
- 普通用户权限即可；程序 manifest 使用 `asInvoker`，不会主动申请管理员权限。

运行时的官方下载地址、文件大小和 SHA-512 见 [运行时版本说明](../runtime/dotnet-desktop-runtime-8.0.29-win-x64/README.md)。

### 启动

1. 从可信的 [GitHub Release](https://github.com/guoqihan342-svg/xlb-pet/releases) 下载 `LubanDesktopPet.exe`，并确认下载版本与该页说明一致。
2. 如发布页提供 SHA-256，先校验文件：

   ```powershell
   Get-FileHash .\LubanDesktopPet.exe -Algorithm SHA256
   ```

3. 双击 EXE。首次启动后，小鲁班默认出现在当前屏幕右下角任务栏上方。

程序使用当前 Windows 会话的单实例锁。已经运行时再次双击，第二个进程会直接退出；请先检查桌面和通知区域中的小鲁班图标。

### 正常退出

可以在任务面板点击“退出”，也可以在 Windows 通知区域右键小鲁班图标后选择“退出小鲁班”。两种方式都会保存待办、定时任务和设置，并立即移除托盘图标。托盘菜单打开后，点击桌面或其他应用会自动收起。

## 2. 常用操作

| 操作 | 效果 |
| --- | --- |
| 左键单击小鲁班 | 从四种可爱动作中随机播放一种，且不连续重复 |
| 待机时点击左上角萌太阳 | 坐到电脑前，用四根手指依次独立落键 |
| 左/右/下普通边缘吸附 | 不显示太阳；先拖回普通待机位置后再开工 |
| 打工时左键单击 | 保持当前打字动作、速度和表情，不出现额外手掌或敲头动作 |
| 打工时左键双击 | 立即把当前动作连续加速到 2 倍；到最近中性接缝后换成认真眉形和专注嘴形并完整保持至少 4 秒；重复双击会续期 |
| 打工时点击左上角萌月亮 | 平滑收工并回到趴枕头待机 |
| 按住左键拖动 | 移动小鲁班；打工中拖动不会退出、重播或改变倍速 |
| 拖到左、右、下边缘后松手 | 普通状态直接吸附并播放探头动画；打工状态跳过普通收工、枕头和待机，直接交给同一边缘的真实探头状态 |
| 右键单击小鲁班 | 以专用托腮思考姿势打开或收起任务面板 |
| 巡游中左键单击 | 原地平滑下坐骑并回到稳定待机 |
| 巡游中开始拖动 | 立即结束巡游并由鼠标接管 |
| 巡游中右键单击 | 平滑下坐骑后打开默认待办页 |
| 点击任务面板外部 | 保存当前有效状态并收起面板 |
| 通知区域右键图标 | 打开退出菜单 |

动画播放期间重复点击不会重新启动同一动作或堆积动作队列。拖动超过 Windows 的拖动阈值后不会误触点击动作。

## 3. 人物动作与待机

- 左键点击会从委屈、欢呼卖萌、点赞和吃饼干四组动作中随机选择；除首次外会排除上一次成功播放的动作，因此不会连续出现同一个动作。正在忙碌而未能启动动作时，不会消耗这次随机历史。
- 每组动作都会从趴枕头待机连续起身，完成动作后再返回待机。
- 没有操作时，约每 1 分钟会从四种动作和打呼噜待机中独立洗牌选择一次；自动袋与用户点击随机历史互不影响。
- 许愿星、旧蝴蝶、失败的 144 帧全人物星星方案、跑步、打哈欠、“嗨～我在这里！”挥手以及普通“让我认真想一想……”动作已经删除，不会出现在点击、自动活动、程序集或发布资源中；`pic/小鲁班1.jpg` 和 `pic/小鲁班8.png` 仍作为用户原始素材保留。
- 右键打开任务面板仍会完整播放并保持托腮思考姿势；该 Todo 专用状态不属于四种普通点击动作，也不会进入空闲随机袋。
- 稳定待机时，鼻尖只显示一个半透明泡泡，人物和枕头不会随泡泡一起缩放。

## 4. 打工模式

- 只有完全稳定的普通待机状态才在人物左上角显示萌太阳。左、右、下普通边缘吸附时不显示入口；先把小鲁班拖回普通位置后即可开工。图标是无文字矢量图形，人物朝向镜像时仍保持在屏幕视觉左上角且脸不会倒转。
- 进入后小鲁班会坐在电脑前持续工作；左食指、右食指、左中指和右中指分别落到不同键位，指节、掌根、手腕和袖口会做幅度很小的自然跟随。认真表情补丁之外的脸、双眼、头、身体、电脑和非目标键盘区域保持逐像素稳定，人物整体比例不变。
- 普通打字每圈有 96 个逻辑帧、65 张独特位图和 9 个精确中性接缝，以 1 倍速每 1.6 秒完成一圈。8 次四指落键采用不等间隔，最长中性停顿只有 5 帧，因此不会像固定节拍器一样机械重复。
- v5 手部动画让指尖、指节、掌根、手腕和袖口按关节层级自然跟随；四根目标手指的实际位移为 `5.528–6.049 px`，认真表情补丁之外的脸、双眼、头、身体、电脑和非目标键盘区域不会跟着抖动。
- 单击人物不会播放四种普通动作，也不会显示敲头手掌；当前打字姿势、绝对相位、速度、普通/认真状态和认真期限全部保持不变。
- 双击人物会立即让当前动作连续加速到 2 倍；到最近的精确中性接缝后，用约 `133 ms` 换成内收眉形和专注嘴形，然后从认真循环开始完整保持至少 4 秒。已在认真打字时再双击，会从当前时刻重新计时至少 4 秒，不重置当前手部姿势。
- 认真打字到期后会等到最近的精确中性接缝，再播放专用表情还原衔接并回到普通 1 倍速，不会在手指落键途中突然硬切。
- 打工中可以直接按住人物拖动；拖动期间绝对时间轴继续前进，未命中吸附边缘时，松手后保持原来的普通或认真打字状态，不重播、不误触双击加速。
- 若松手时命中当前显示器工作区的左、右、下外边缘，程序会锁定该边缘并完全跳过普通收工动画、趴枕头和待机状态，直接把当前工作画面交给同一边缘的普通探头状态；顶部与双屏内部接缝不吸附。
- 如果目标边缘图集页已经驻留，会在同一次渲染提交中从当前工作姿势原子切到 edge-rest。若目标页尚未解码，人物会冻结当前工作姿势，直至 edge-rest resident 后再切换；不会继续普通 `work-exit`，也不会用枕头或待机画面填补等待时间。只有目标页加载失败才安全回到待机。
- 打工后太阳会用约 `420 ms` 的轻压、下沉旋转、弹入和柔光动画原位变成萌月亮；点击月亮请求收工时会当帧连续反向切回太阳，即使快速反向操作也不会硬切或闪白。未通过拖动请求边缘收工时，点击月亮可以平滑回到趴枕头待机。打工期间自动动作、呼噜和熊猫巡游暂停；右键和定时提醒仍可按原优先级接管。
- 打工状态只保留到本次运行，不写入设置文件；重新启动仍从普通待机开始。

桌宠主窗口、任务面板、提醒、确认和编辑窗口不会出现在 Windows 的 `Alt+Tab` 切换列表中；这只隐藏切换入口，不会阻止窗口激活，也不影响输入法、复制、焦点、拖动、置顶或提醒操作。

## 5. 屏幕边缘探头

- 只支持屏幕工作区的左、右、下边缘吸附。顶部是普通可拖动区域：人物可见内容可以贴到当前显示器工作区最上沿，但不会吸附或播放探头动画。
- 人物可见边缘进入当前显示器工作区边界内约 `12 DIP` 的磁吸区，或快速稍微越过边缘后松手，会进入探头状态。
- 每轮按“藏起来 → 偷看 → 开心探头 → 害羞缩回”播放，完整周期约 10 秒。进入吸附时先停在末尾藏好姿势，随后按 `v1.0.57` 的节奏开始首轮探头。
- 侧边探头的下手贴住边界，袖口与前臂收成短而圆的上扬弧线并藏到脸下，不再出现横向紫色长袖或平切底边；右侧精确镜像左侧同一套帧。下边缘仍使用原有双手扒边姿势。
- `v1.0.66` 进一步补全下手后方可见的短弯前臂：浅探时能看清手腕后的连续袖臂，深探时前臂自然延伸并收进脸下，不会只剩手掌和一小截袖口，也不会恢复 `v1.0.64` 的横向紫色长管。
- 视觉判断以真实 `190×242 DIP` 人物显示区域为准；在 75%（`0.75`）与 140%（`1.40`）桌宠大小下，左、右侧的浅探和深探都应保持前臂完整、边缘圆润。右侧必须是左侧精确镜像，Bottom 仍为原有双手扒边动作。
- 再次拖离边缘会恢复普通待机和随机动作。
- 左上角、右上角如果同时触及侧边，分别按左、右边缘处理；顶部中央仍不吸附。
- 任务面板打开时也能拖到边缘；松手进入左、右或下吸附的一刻会提交当前待办行内修改，并自动关闭整个“待办事项 / 定时任务”面板。边缘探头继续运行，不会被任务面板退出动画抢占或迟到回调重新打开。

每块显示器独立使用自己的 `WorkArea`，因此支持副屏负坐标、不同 DPI、不同任务栏位置以及显示器热插拔。

## 6. 熊猫坐骑巡游

- “绕屏动画”默认开启。
- 小鲁班连续空闲约 10 分钟，并且没有提醒、拖拽、任务面板、其他动作、尺寸调整或边缘探头时，会登上熊猫坐骑沿当前显示器工作区巡游。
- 到期时如果程序正忙，会在约 20 秒后重试，不会重新等待完整 10 分钟。
- 巡游中左键单击会就地停止移动、平滑下坐骑并回到稳定待机，不会再额外播放四种点击动作。
- 左键动作超过拖动阈值后会立即结束巡游的位置控制，再把窗口交给鼠标拖动。
- 巡游中右键会先在当前位置平滑下坐骑，退场完成后再打开默认待办页，不会先闪出站立帧或瞬移回路线起点。
- 定时提醒或手动边缘吸附也会优先结束巡游。上述交互结束后，下一次巡游重新按约 10 分钟空闲期限安排。
- 取消勾选“绕屏动画”只关闭熊猫巡游，不会关闭四种原地动作或手动边缘探头。
- 自动路线可以经过顶部，但这不等于恢复手动顶部吸附。

绕屏开关保存在 `settings.json`，下次启动继续沿用。

## 7. 待办事项

右键小鲁班打开任务面板后，默认显示“待办事项”页。

### 新增与完成

- 在底部输入框输入内容，按 `Enter` 或点击“新增”。
- 每条待办最多 5000 字。
- 点击行内蓝色勾选框切换完成状态。
- 勾选完成后，该项会自动移动到列表最底部，其他项目的相对顺序不变。
- 取消完成只改变完成状态，不会自动移回顶部；仍可通过左侧 `≡` 手动调整顺序。
- 文字、完成状态和当前顺序都会自动保存。

### 修改、复制与排序

- 单击右侧铅笔图标，或选中当前行正文后按 `F2`，打开独立修改窗口。
- 只有点击“确定修改”才保存；按 `Esc` 取消。点击窗口外部不会自动保存未确认草稿。
- 正文支持选择和 `Ctrl+C`。新增与修改输入框使用原生 `Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+A`。
- 微软拼音仍在组词时，`Enter` 只用于选词，不会误新增待办；搜狗输入法继续使用标准文本输入路径。
- 从行左侧 `≡` 手柄拖动可以调整顺序，不会抢占正文选择。
- 长文字确实被裁掉时，鼠标悬停会显示可选择复制的全文窗口；短文字不会弹出。
- 鼠标经过待办行时，整张卡片同时显示浅蓝底和完整蓝色圆角描边；普通项和已完成项使用同一悬停结构。行上方、下方不会出现独立横线。拖拽排序时的一条插入提示线属于另一种状态，不是悬停边框。

### 删除

点击待办行右侧蓝色垃圾桶。默认会显示蓝色确认窗口；勾选“本次运行不再提示”只影响当前进程，重启后恢复确认。

## 8. 定时任务

切换到“定时任务”选项卡后，可以创建单次或循环提醒。

### 创建与修改

- 正文最多 5000 字。
- 日期使用固定六周月历，支持上月、下月、跨年、闰年和“今天”。
- 时间使用时、分、秒三列选择器，精确到秒。
- 单次任务必须选择未来时间。
- 点击行内铅笔图标可修改正文、日期、时间、循环规则和免打扰；只有“确定修改”会保存，`Esc` 取消。
- 日期框支持 `Space`、`Enter`、`↓` 或 `F4` 打开，`PageUp / PageDown` 换月，`Esc` 关闭当前选择器。

### 循环规则

循环单位只有分钟、小时和天，最小有效间隔为 1 分钟：

- 每 N 分钟：保持所选秒数。
- 每 N 小时：保持所选分、秒。
- 每 N 天：保持所选时、分、秒。

如果循环任务选择的本轮时间已经过去，程序会沿原始节奏推进到严格晚于当前时间的下一次，不会从保存时刻重新计时。规则、下一次时间和循环序号都会写入 `scheduled-tasks.json`，电脑重启后仍然有效。

创建或修改任务时会记录当时的系统时区。后续循环和夏令时边界继续按该任务保存的时区计算；以后更改 Windows 系统时区不会自动改写已有任务。如需让旧任务采用新时区，请打开修改窗口确认日期、时间后重新保存。

### 每日免打扰

- 只对循环任务提供。
- 默认时间为 `22:00:00–07:00:00`，支持精确到秒和跨午夜。
- 开始时间不能与结束时间相同。
- 免打扰期间不弹窗、不播放喇叭动画，也不确认或丢弃发生项；结束后按原节奏汇总提醒。

### 到点提醒

- 小鲁班会中断普通动作，临时平滑放大到 140%，举起喇叭并显示独立提醒窗口。
- 正在编辑待办或定时任务时，原面板、选项卡、草稿和焦点不会被提醒窗口清空。
- 提醒窗口每页最多 5 条；当前批最多载入最早的 100 个发生项，超过部分会在确认后继续显示。
- “知道啦 / 本批都知道啦”、右上角 `×`、`Esc` 和系统关闭都会确认当前实际载入批次。
- 单次任务在确认后删除；循环任务按本批实际发生次数推进。未确认前退出或崩溃不会静默丢失记录。

程序必须处于运行状态才能实时弹窗。电脑休眠、关机或程序退出期间，任务仍保存在磁盘；下次启动后会重新加载并处理已经到期的记录。

## 9. 设置

任务面板底部包含：

- “绕屏动画”：默认开启，仅控制熊猫坐骑巡游。
- “开机自启”：默认关闭，写入当前用户的 Windows `Run` 注册表项，不需要管理员权限。
- “桌宠大小”：75%～140%，拖动笑脸圆钮连续调整。

绕屏开关和桌宠大小保存在 `settings.json`。开机自启不写入该文件。如果移动了 EXE，手动运行新位置的 EXE 后，程序会检查并修复已经启用的旧启动路径。

## 10. 数据备份、升级与卸载

### 数据位置

```text
%LocalAppData%\LubanDesktopPet\
├─ todos.json
├─ scheduled-tasks.json
└─ settings.json
```

### 备份与恢复

1. 从托盘正常退出小鲁班。
2. 复制整个 `%LocalAppData%\LubanDesktopPet` 文件夹到备份位置。
3. 恢复时确保程序未运行，再用备份文件覆盖或替换对应 JSON。

不要在程序运行时同时用文本编辑器修改这些文件，以免外部修改与自动保存互相覆盖。

### 升级

1. 正常退出旧版本。
2. 备份本地数据目录。
3. 用新版 EXE 替换旧文件或放到新目录运行。
4. 如果已启用开机自启，打开一次任务面板确认开关状态和启动路径已经修复。

### 卸载

1. 在任务面板中关闭“开机自启”。
2. 从托盘正常退出。
3. 删除 `LubanDesktopPet.exe`。
4. 如不再需要历史待办和提醒，可自行备份后删除 `%LocalAppData%\LubanDesktopPet`；保留该目录不会继续运行程序。

## 11. 常见问题

### 双击 EXE 没有出现第二个小鲁班

这是单实例设计。先检查桌面和通知区域；若已有实例，请使用现有实例或先正常退出。

### 完全无法启动

确认系统为 Windows x64，并安装 x64 `.NET 8 Desktop Runtime`。框架依赖 EXE 不能只靠一个文件在未安装运行时的电脑上启动。

### SmartScreen 显示未知发布者

当前 EXE 未做商业代码签名。只应从可信 Release 下载，并核对发布方提供的哈希；文档不会建议绕过 Windows 安全策略。

### 为什么 10 分钟后没有立即巡游

10 分钟是连续空闲到期时间。任务面板、提醒、拖动、动画、尺寸调节或边缘探头会阻止当下出发；到期但忙碌时约 20 秒后重试。还要确认“绕屏动画”已勾选。

### 为什么提醒暂时没有弹出

检查任务是否为未来时间、程序是否正在运行，以及该循环任务是否处于免打扰时段。电脑休眠或程序退出期间不会实时弹窗，恢复或重启程序后会根据持久化记录处理到期项。

### 移动 EXE 后开机自启失效

从新位置手动启动一次程序，再打开任务面板。已启用的旧路径会被检查并修复；如仍失败，先关闭再重新开启“开机自启”。

### 数据文件损坏或被占用

定时任务加载失败时会进入只读保护，避免退出时把原文件覆盖成空列表。先退出程序，备份原文件，再检查文件权限、占用进程或 JSON 内容。不要直接删除唯一副本。

### 去哪里找日志

当前版本明确关闭文件日志，不会创建 `log` 文件夹。排查时请记录复现步骤、系统缩放、显示器布局、EXE 版本和截图。
